# BioDesk

**Acesso remoto seguro — uso interno da BioMessenger.**

O BioDesk permite que a equipe da BioMessenger acesse e opere, remotamente, os
computadores e servidores dos clientes, com conexão criptografada.

## Baixar e acessar

- **Site:** https://tecnologia-biomessenger.github.io/biodesk-servers/
- **Windows:** instalador na página de [Releases](https://github.com/tecnologia-biomessenger/biodesk-servers/releases)
- **Celular / navegador:** https://tecnologia-biomessenger.github.io/biodesk-servers/controle.html

O aplicativo se **atualiza sozinho** — não precisa reinstalar a cada versão.

## Suporte

Dúvidas ou problemas: fale com a equipe de Tecnologia da BioMessenger.
